# What Makes Institutional Vault So Secure?

The Institutional Vault uses Blockdaemon's patented Advanced MPC Threshold Security Module (TSM), a wallet security platform that combines robust private key protection with easy accessibility. It is designed to deliver the ideal mix of private key security and accessibility. The off-chain nature of safe Multi-Party Computation (MPC) enables multi-party approval enforcement, which previously needed MultiSig, in a more flexible, efficient, and blockchain-compatible manner. It employs a cloud-native microservices architecture to facilitate unparalleled flexibility, scalability, and availability.

TSM also offers unique pre-processing algorithms to reduce latency for high-frequency trading, along with offline, air-gapped MPC options. 

<Image align="center" width="600px" src="https://files.readme.io/fb0ab59-75b9a946-a40d-44d8-9654-9f49bd0e1c37.png" />

By implementing TSM, the Institutional Vault gains enhanced security and these optional features:

* Increased security results from never generating or storing an entire key on any device.
* Highly scalable, intended for wallet models per user and supporting various transactions on chain.
* Enhanced transaction confidentiality by removing multiple signatures on the blockchain.
* Lower transaction sizes to increase the number of transactions per block and reduce mining costs.
* Practical assistance for incredibly advanced types of m and n approval.
* Enables approval for all digital messages, even those that don’t support built-in multi-signature (MultiSig) features.
