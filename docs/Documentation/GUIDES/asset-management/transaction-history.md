# Overview

Under the Transaction History, you may examine every received or initiated transaction in the Institutional Vault. The history is shown in a table that may be filtered according to your needs.

> 📘 Note:
>
> You can click the **Queue New Entries** toggle button. This will prevent new transactions from being automatically loaded into the transaction history. Instead, they will be bundled at the top of the list, detailing how many transactions are currently queued. You can then choose to load them in manually.

# View the Transaction History

To view the transaction history, follow the steps below:

1. Click **Transaction History** on the main navigation menu.

<Image align="center" src="https://files.readme.io/97b3ce617825a0ff5fa219311e2c0c4c56a094b99c2baf27fbd4c75bb8e9d49d-Group_18_-_2024-09-12T144342.926.png" />

2. In this section, you can see your wallet transaction history.

# Set the Column

To set the column to be displayed, follow the steps below:

1. Click **Transaction History** on the main navigation menu.

<Image align="center" src="https://files.readme.io/d3f1922166b2fa3f65fdc57ab5fec9d8fb0d6c55e196f9528353b11f400496a2-Group_18_-_2024-09-12T144342.926.png" />

2. Click the **Set Columns drop-down** button to change the columns displayed in the table. For example, deselect the **Created date**. The table is updated to no longer display the **Created date** column.

<Image align="center" src="https://files.readme.io/b5d325c1bd4558c19d2be2b7de63e8f6c8c630903575c19fac2d6ad5e9e087d2-Group_18_-_2024-09-12T144456.920.png" />

# Set the Filter

To set the filter, follow the steps below:

1. Click **Transaction History** on the main navigation menu.

<Image align="center" src="https://files.readme.io/10ea69640c5ed793f64610d46c5e4250da71d8dafab3b05b53690c6631237ef0-Group_18_-_2024-09-12T144342.926.png" />

2. Click the **Select Filters** button.

<Image align="center" src="https://files.readme.io/881dc092e86180e08e11825b5a5409d85e3fe6da5e1223e5f85055e627da0e85-Group_18_-_2024-09-12T144542.000.png" />

3. Select the filter you want to apply.

<Image align="center" src="https://files.readme.io/9bf82ec2d844e9b020edc9593c535c0e647c7ddb650116f0cb6ff45879581bec-Group_18_-_2024-09-12T144708.467.png" />

> 📘 Note:
>
> Given that you've already received funds, you will have at least one account accessible for choosing in the Source Accounts section.

4. Click **Filter** to enable your filter.

<Image align="center" src="https://files.readme.io/e648ecf5a94b7474f0bb5128d08315915eb909a06abdbc894150186f8ed352c0-Group_18_-_2024-09-12T144655.015.png" />

6. Clear the filter by clicking the **Clear all Filters** button at the top of the table. The filter is cleared, and you can see all transactions again.

<Image align="center" src="https://files.readme.io/c8b5ab21f3d3af4d86d906294dfb15c8ba7288e038002b68ed26f591c151bebf-Group_18_-_2024-09-12T144844.805.png" />

# View the Transfer Details

To view the transfer details, click the **Transfer details** button on the selected transfer list to see all available information about this transaction.

# Export the Transaction History

To export the transaction history, follow the steps below:

1. Click **Transaction History** on the main navigation menu.

<Image align="center" src="https://files.readme.io/59c9f36491f7b7548a17b4eeb6da7a32cf118ed8d1d8f3522ecea64e642875a4-Group_18_-_2024-09-12T144342.926.png" />

2. Click the **Export** button on the top right side of your screen. The Transaction History list is exported and downloaded to the user's device as a **CSV file**. 

<Image align="center" src="https://files.readme.io/3ddbad6288c0dbec8a65362d7c3376572da30e74d10df3b0dba50a376d0f6f7f-Group_18_-_2024-09-12T145018.390.png" />

> 📘 Note:
>
> * If the Transaction History is filtered, only the transactions included in the filter will be exported. 
> * The Set Columns function does not affect the export. 
> * All available information for each transaction will always be part of the download.
