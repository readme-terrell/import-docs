# Overview

Freeze is an action that immediately halts the generation of any new Institutional Vault transfers. Until the wallet is unfrozen, no user can create new transfers using the wallet. A confirmation request is simultaneously made to the **administrator** who froze the wallet. If/when this confirmation request is granted, the policy engine will halt all transfer activities (including those in progress but not yet broadcast).

> 📘 Note:
>
> This operation is only available to **Administrator Users** in the Institutional Vault's settings menu.

# How to Freeze the Wallet

To freeze the wallet, follow the steps below:

> 🚧 Warning:
>
> Proceed with caution!

1. Click the **Settings** button on the main navigation menu.

2. Click the **Freeze** button next to the Backup Key on the top-right side of your screen.

3. Select **Freeze** once again to confirm the operation.

# How to Unfreeze the Wallet

To unfreeze the wallet, follow the steps below:

1. Click the **Settings** button on the main navigation menu.
2. Click the **Unfreeze** button next to the Backup Key on the top-right side of your screen.
3. Select **Unfreeze** once again to confirm the operation.
4. Approve the Unfreeze request in the **Institutional Vault Approver** application to confirm the operation.

> 📘 Note:
>
> Only **administrator** users can unfreeze the wallet.
