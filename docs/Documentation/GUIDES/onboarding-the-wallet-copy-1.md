# Overview

To onboard the Institutional Wallet, sign in through your company's identity provider (Auth0 for the demo environment). To set up the **Institutional Wallet Approver** app, you need a device that supports biometrics. Install the application from the iOS app store and ensure you have set up and can use the biometrics feature on your device.

# How to Onboard the Institutional Wallet

To onboard the wallet, follow the steps below:

1. Sign Up to create an account by clicking the **Sign Up** button.

<Image align="center" width="500px" src="https://files.readme.io/43aba91-Group_42_32.png" />

2. Once you have an account, **Sign in** to the web wallet.

![](https://files.readme.io/805eb75-ezgif.com-video-to-gif_10.gif)

3. Install the **Institutional Wallet Approver** on your iOS device on the iOS app store, and set up the environment.
4. Use the **Institutional Wallet Approver** to scan the QR code in the web wallet console. This will link the approver app with your wallet environment. 

> 📘 NOTE:
>
> You must allow the application to access your camera.

5. **Confirm** that you are linking up to the environment that you expect to.

![](https://files.readme.io/46cff05-ezgif.com-video-to-gif_11.gif)

> 📘 Note:
>
> The **QR setup** screen may appear differently from the image above, as the image shown represents the setup screen for a local development environment using the iOS app.

6. Sign in to the **Institutional Wallet Approver** application using your company's credentials.

![](https://files.readme.io/260e508-ezgif.com-video-to-gif_12.gif)

7. Once successfully signed in, add a **PIN code** for authentication.

![](https://files.readme.io/e5aa12a-ezgif.com-video-to-gif_13.gif)

8. Register your **private key** to enable you to sign operations.
9. Once the key has been registered, it can access the web wallet.

![](https://files.readme.io/d58962c-ezgif.com-video-to-gif_14.gif)

10. To access the Wallet, administrators must **back up the environment's master key**. 

> 📘 Note:
>
> Please make sure that your administrators create a backup of the master key.

![](https://files.readme.io/9736cd6-ezgif.com-video-to-gif_15.gif)

11. Finish the **Institutional Wallet Approver** application setup by allowing notifications. **(Optional)**
