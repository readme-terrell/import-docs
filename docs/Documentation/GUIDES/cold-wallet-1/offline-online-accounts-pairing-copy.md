## Overview

The Blockdaemon Institutional Vault offers secure offline storage with our new cold wallet feature. It uses two separate MPC nodes, each giving part of the signature needed to approve a transaction. These nodes are kept in two different cold wallets for added safety. The system supports both hot and cold wallets, and pairing them lets you use features like creating transactions and setting rules. You'll need accounts for both wallets to pair them.

> 📘 Note:
>
> * Remember that Hot Wallet and Cold Wallet are separate entities.
> * You can choose to have 2 separate cold wallets with one node each or go with the original format of just one cold wallet containing both nodes.

## Pairing the Hot & Cold Wallet

To integrate the Hot and Cold wallet, follow the steps below:

1. Navigate to the settings page in the hot wallet.

2. Click the Wallet Pairing tab.

3. Click Download Hot Pairing Message.

4. Save the message in a trusted USB stick.

5. Plug the USB into the cold wallet device.

6. Navigate to the settings page in the Cold Wallet.

7. Click the Wallet Pairing tab.

8. Click the Upload the Hot Pairing Message.

9. Select the Hot Pairing Message file.

10. Click Upload.

11. Once Uploaded, Click the Download the Cold Pairing Message.

12. Save the message in a trusted USB stick.

13. Navigate back to the Hot Wallet.

14. Plug the USB into the hot wallet device.

15. Click Upload Cold Pairing Message in the settings tab.

16. Select the file and click Upload.

> 📘 Note:
>
> Keep in mind that the security architecture involves both the parent keys and a multi-layered security system structure. As a result, even if the parent keys are compromised, the overall security of the system remains resilient and intact.
