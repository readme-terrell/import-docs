# Overview

A user must be set up in the wallet settings menu to access the wallet. A user is registered with the email they use for the company’s identity provider and given a display name for the wallet and a role. 

> 📘 Note:
>
> Notifications about older or pending operations will not be visible in the approver app for recently registered owners.

# How to Register a User

You can register a new user by following the steps below:

> 📘 NOTE:
>
> Only users with the administrator role can register users.

> 🚧 Warning:
>
> Registered users must verify their identity within 60 minutes of being added to the wallet.

1. Go to the **Settings** menu. 

> 📘 Note:
>
> This menu is only accessible to administrators.

<Image align="center" src="https://files.readme.io/8e8c0510f69371261df0679b1e4367767859ce36f933efc5cc6be39b6a005fb5-Group_18_-_2024-09-10T140320.704.png" />

2. Within the Settings menu, under the **User** tab, select **Register User**.

<Image align="center" src="https://files.readme.io/590cf7c09b383bfdd3ba7b848de54a511b1a28014583cca10bfcb04dd07a34e5-Group_18_-_2024-09-10T142623.832.png" />

3. Fill out the email with your company's credentials.

<Image align="center" src="https://files.readme.io/37808b5b58a8774be5f35edc3fa64f97f0961975ce743dec18ad36598a18c187-Group_18_-_2024-09-10T142602.658.png" />

4. Fill out the name displayed for the user in the wallet.

<Image align="center" src="https://files.readme.io/041fc44bf25b68495496725500d94debea55608b1ceacc6a7cea1743a2fc8e4f-Group_18_-_2024-09-10T142546.798.png" />

5. Choose which role the user should have.

<Image align="center" src="https://files.readme.io/6ba05be41523753d331543d56919aa6e0932c6a6160de42b8ca7aaa800cae78e-Group_18_-_2024-09-10T142528.093.png" />

6. Click **Register** to submit the operation for registering a user.

<Image align="center" src="https://files.readme.io/fb56735bd51409c6a2e92803bb6210fa08f58f5d7fc6224000077ddaa1fbaa51-Group_18_-_2024-09-10T142506.973.png" />

7. You will receive a notification that asks you to confirm the operation. Verify the operation and confirm it.
8. When an operation has been confirmed, it is evaluated for approval requirements. The relevant users are notified through the Institutional Vault Approver if approval is needed.
9. When the operation has cleared approval, the user is successfully registered.

# User Roles

The Institutional Vault offers three distinct user roles: **Admin**, **Viewer**, and **MarketOps**. Each role possesses different capabilities and privileges, governing their access to various features within the Institutional Vault. To see the differences between roles, please see [here](https://vault.docs.blockdaemon.com/docs/user-types-and-privileges).

> 📘 Note:
>
> The registered user will have the “Pending Onboarding” status and must go through the onboarding flow to access the wallet.
