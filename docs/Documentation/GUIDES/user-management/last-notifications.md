# Overview

Last notification is a feature of the Institutional Vault that notifies you of significant events when an operation reaches an end state. Operations have reached their end-state when either:

* The operation was completed. In cases where approval is necessary, this indicates that it has passed the approval process.
* The operation was rejected. This signifies that the operation was declined due to the confirmation step or approval process.
* The operation was failed. This implies that the task could not be completed due to a system-related problem. Notifications for unsuccessful tasks will include an error code and a brief explanation of the cause behind the failure.

What constitutes important events differs based on your role in the wallet:

* Rejected, failed, or completed operations are important events for the user who initiated them.
* If a new user successfully onboards the wallet, all users consider this an important event.
* Effectively removing or resetting a user is an important event for the administrator role.
* Modifying Transfer Policies, adjusting Exchange Rate Boundaries, or establishing Groups are all deemed important events for the admin role.

For the following operations, only the admin user who commences the wallet operation will receive a confirmation notification on their approver app:

* Register a User.
* Delete a User.
* Reset a User.
* Create a System User.
* Add a user to a group.
* Remove a user from a group.
* Edit the wallet policy.
* Add an ERC-20 token.
* Edit exchange rates.
* Back up the master key.
* Stake Assets.
* Freeze the wallet.

> 📘 Note:
>
> Notifications are displayed in the Last Notifications list for a duration of up to seven days.

# View the Notifications

To view the notifications, follow the steps below:

1. Navigate to your Institutional Vault.

2. Click the **bell icon** on the homepage menu next to your account name.
