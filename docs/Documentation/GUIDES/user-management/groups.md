# Overview

Every user in the wallet can be a member of just one group at most. If a user isn't associated with any specific group, they automatically become a part of the **All Approvers** group. The group attribute can affect policies in two ways:

1. We can determine the group to which the operation initiator belongs.
2. We can identify the approval needed for an operation from a specific group.

# Create a Group

To create a group, follow the steps below:

> 📘 Note:
>
> Only an administrator can do this operation.

1. Select **Settings** on the main navigation menu.

<Image align="center" src="https://files.readme.io/afbfe96e4fcc1f3705eb04a83284557a80e097a17cb24325f1f0e985aa61bb8a-Group_18_-_2024-09-10T140320.704.png" />

2. Click the **Group** tab.

<Image align="center" src="https://files.readme.io/59127bc12960db0fca9aa3e0ee6d18becb5100aba157a7303a114e2f9d891b05-Group_18_-_2024-09-10T143636.869.png" />

3. Click the **Add Group** button.

<Image align="center" src="https://files.readme.io/1b2e5987bc4f13d37fb9e8b1abcb17dbd250868115819d921bad0cf6f0b7f5df-Group_18_-_2024-09-10T144402.506.png" />

4. Enter the **Group Name**.

<Image align="center" src="https://files.readme.io/63748eb2cda9ccf64b7ecdba93698fa909840bb70f6bb2e1ba4879cd75f0bd3e-Group_18_-_2024-09-10T144826.706.png" />

5. Click **Create** to create the group.

<Image align="center" src="https://files.readme.io/1e3813bd444b332a4bdb9ee06957cd81e42a2028290f1a77d0549eac4b238e95-Group_18_-_2024-09-10T144837.512.png" />

# Add a User to a Group

To add a user to a group, follow the steps below:

> 🚧 Warning:
>
> If a user is added to a group but not authorized by the appropriate user, they may remain in the **Pending Confirmation** state. As a result, the operation will be rejected after the permission request has expired (the default is one week). The expiration time can be changed.

> 📘 Note:
>
> A user can only belong to one group. Make sure the user isn't already in another group before adding them.

1. Select **Settings** on the main navigation menu.

<Image align="center" src="https://files.readme.io/22bb94533d280be6756f0767309d2ce160a7e615f8693c8422925f34ddb14601-Group_18_-_2024-09-10T140320.704.png" />

2. Click the **Group** tab.

<Image align="center" src="https://files.readme.io/b6441ce23e2b9ff1fd066b3cedaa2105a3baa2b029b314b0196ef6ea7fd0abca-Group_18_-_2024-09-10T143636.869.png" />

3. Select a **group**.

<Image align="center" src="https://files.readme.io/6ee6cb536e303ed1216734ae727f3ede700d59564d0db46af82af62175d87fec-Group_18_-_2024-09-10T163343.408.png" />

4. Click the **Add Users** button.

<Image align="center" src="https://files.readme.io/defa503079e9a80ede123f71f75ab1f4945e176b935bb66b8f2e72ee0c13ee12-Group_18_-_2024-09-10T163702.659.png" />

5. A drop-down menu will appear. Select the user you want to add to the group.

> 📘 Note:
>
> It's possible to add multiple users to the group at the same time.

6. Click **Add User(s)** to confirm the operation.

<Image align="center" src="https://files.readme.io/c8cf41e6c8cc9deb446438ae580cce393f2937ebb54c841f4244cc0a83df6450-Group_18_-_2024-09-10T164029.272.png" />

> 📘 Note:
>
> You must confirm this operation on your Institutional Vault Approver app, and according to the administrative policies of the wallet, additional approvals may be required.

1. Select **Settings** on the main navigation menu.

<Image align="center" src="https://files.readme.io/92569fbcff5a885d834aeefd352f32eed37e235aaf9f30cb0678b71aeffe0811-Group_18_-_2024-09-10T140320.704.png" />

2. Click the **Group** tab.

<Image align="center" src="https://files.readme.io/70d636ca39851fb8b45699d2ec42ba7c8a2e027b6f79becacbe5d2b74ad38740-Group_18_-_2024-09-10T143636.869.png" />

3. Select a **group**.

<Image align="center" src="https://files.readme.io/d6fca6f7b168d64760978d2e0dabd5cb883602997aca918b6978c81d897c73b4-Group_18_-_2024-09-10T163343.408.png" />

> You must confirm this operation on your Institutional Vault Approver app, and according to the administrative policies of the wallet, additional approvals may be required.
