# Overview

If a user does not belong to a group, an administrator may remove them.

> 📘 Note:
>
> Ensure the user does not belong to any groups before beginning the user deletion procedure.

# How to Delete a User

To delete a user from your wallet, follow the steps below:

1. Click the **Settings** menu on the main navigation.

<Image align="center" src="https://files.readme.io/6f24927ef775cf76d498e68c1ad8a3823d0c80ed309a66b1d0c937e6ea3d8296-Group_18_-_2024-09-10T140320.704.png" />

2. Select the user you want to delete under the Users tab.
3. Click the **Overflow icon** next to the user.

<Image align="center" src="https://files.readme.io/a83749114f6daef91efd48b5a85d973084e53cfffbdae502408a6500ea4b5289-Group_18_-_2024-09-10T142424.702.png" />

4. Select **Delete User**.

<Image align="center" src="https://files.readme.io/5492928761a079766c74b7022e20d1d8b5a145dde570979696e978578a1486b0-Group_18_-_2024-09-10T143019.543.png" />

<br />

5. You will receive a notification that asks you to confirm the operation. Verify the operation and confirm it.
6. When an operation has been confirmed, it is evaluated for approval requirements. The relevant users are notified through the Institutional Vault Approver if approval is needed.
7. When the operation has cleared approval, the user is successfully deleted.
