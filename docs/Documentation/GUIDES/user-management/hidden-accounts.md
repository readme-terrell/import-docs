# Overview

You can hide certain accounts in the Institutional Vault. Many of these accounts will primarily serve for deposit purposes, are unnecessary for day-to-day operations, and can remain hidden. If you need to access these accounts, you can search for the account's name directly in the Find Account feature.

> 📘 Note:
>
> Accounts made through system calls will be marked as hidden by default.

# Hide an Account

To hide an account, follow the steps below:

1. Click the **Account** menu button on the main navigation menu.

<Image align="center" src="https://files.readme.io/d16cee0af8e6ebcd47b73219c13a5be12bc1fe5ed62e04813a7da9d1529259fb-Group_18_-_2024-09-10T140320.704.png" />

2. Choose the account you want to hide. 

> 📘 Note:
>
> Ensure that you have already noted down the account name before marking it as hidden

3. Click the **Overflow** button. This displays a list of available actions.

<Image align="center" src="https://files.readme.io/8fb552aed7148220b27eba9d98ab7144376f0e677f32798e7f529b00a4e39df7-Group_18_-_2024-09-10T164833.582.png" />

4. Click the **Hide** button to hide the account. The account is hidden instantly and no longer displayed in any of the lists in the wallet. 

<Image align="center" src="https://files.readme.io/49dd05ef436454967b08418408fd4294d2a1587bcbf686c20f738724a0db1092-Group_18_-_2024-09-10T164953.330.png" />

> 📘 Note:
>
> Within the Assets menu, the overall balance of each asset continues to include the amount stored in the hidden account, as these funds are still within the wallet.

# Unhide an Account

To unhide an account, follow the steps below:

1. Click the **Account** menu button on the main navigation menu.

<Image align="center" src="https://files.readme.io/bd8bf5961c3d5f15fdb19748b55aa53cbef647f54a8dbcc51db477af33eb509b-Group_18_-_2024-09-10T140320.704.png" />

2. Click the **Find Account** button.

<Image align="center" src="https://files.readme.io/f49137d6a9d12e0f96b63362493b4f7ec2ba527328a04087d2e8eb05f82bb9f5-Group_18_-_2024-09-10T165111.295.png" />

3. Search for the Account you are trying to access by typing in the Account name. 

> 📘 Note:
>
> The name needs to be an exact match. If not, the account is inaccessible and cannot be identified.

4. If the searched name matches a hidden account, the account will appear in the list of the **Find Account** menu.

<Image align="center" src="https://files.readme.io/c254ddce1c729b7ddb93adc8bcfc3bc12c8b8a3d06b11a3510a1d9b1b404678c-Group_18_-_2024-09-10T165256.154.png" />

5. Click the **Overflow** button.

<Image align="center" src="https://files.readme.io/e598078d7b10305c3ca91b8524e518d30a372109b28bc84e6c23dbfc58632686-Group_18_-_2024-09-10T165531.078.png" />

6. Select **Unhide** to unhide the account.

<Image align="center" src="https://files.readme.io/180fc03da93eff3a00d24daa5f285a7dad9d30a550c77c00c103cfce80072391-Group_18_-_2024-09-10T165705.854.png" />
